# LiteBoard 编辑器瘦身重构需求文档

> 日期：2026-06-08
> 参考方向：DataEase 仪表盘编辑页
> 当前状态：已确定方案，本阶段先记录需求，后续按本文档实施。

## 1. 背景与目标

当前 LiteBoard 编辑器已经打通了数据集、图表、文本、普通表格、保存恢复和导出等基础能力，但编辑器外壳偏重：左侧常驻面板占用空间，新增组件依赖弹窗，右侧配置偏工程化，JSON 数据预览过于显眼，整体更像调试工具而不是仪表盘设计器。

下一轮重构目标是：**保留现有功能和 schema，不重写后端，把编辑器改成更接近 DataEase 的轻量工作台**。

核心体验目标：

- 顶部是简洁组件工具栏。
- 中间把空间留给画布。
- 右侧只处理当前组件配置和数据字段。
- 普通用户优先看到低代码配置，高级 JSON / JS 能力收进高级区域。
- 不继续堆组件数量，先把编辑器信息架构收干净。

## 2. 布局需求

编辑器整体改为三块：

- **顶部工具栏**：返回、撤销/重做占位、组件添加入口、预览、保存、发布占位。
- **中央画布**：只显示画布和组件，保留选中框、拖拽、缩放、浮动操作条。
- **右侧配置区**：选中组件后显示配置；未选中时显示轻量引导。

需要移除或收敛当前左侧常驻大面板：

- “画布调整”不再常驻左侧，可移到顶部或右侧画布设置入口。
- “当前数据集 JSON 预览”不再常驻展示。
- “添加组件”迁移到顶部工具栏。

## 3. 顶部工具栏需求

顶部工具栏参考 DataEase 的紧凑模式，组件入口按类别分组：

- 图表
- 查询组件
- 富文本
- 媒体
- 表格
- 更多
- 复用

v1 实际落地：

- “图表”下拉：柱状图、折线图、饼图、散点图、雷达图、仪表盘、漏斗图。
- “富文本”：添加文本/标题组件。
- “表格”：添加普通表格组件。
- “查询组件 / 媒体 / 更多 / 复用”先作为占位入口或隐藏，避免出现不可用功能误导用户。

新增组件交互调整：

- 点击组件类型后直接上屏。
- 不再打开“初始化图表配置”弹窗。
- 默认字段可自动选择；不满足条件时在右侧数据配置区提示。
- 所有后续调整都在右侧配置区完成。

## 4. 画布需求

中央画布要尽量干净：

- 默认背景保持浅灰工作区 + 白色画布。
- 组件选中时显示蓝色边框和缩放点。
- 选中组件旁显示小型浮动操作条：复制、删除、置顶、置底、更多。
- 空画布只显示极简提示，不显示大面积说明。
- 数据绑定错误不在画布上长篇解释，只显示简短状态，详细原因放到右侧配置。

画布相关能力保留：

- 拖拽移动。
- 缩放尺寸。
- 层级调整。
- 保存状态提示。
- 预览模式。

## 5. 右侧配置区需求

右侧参考 DataEase 的“双栏”结构：

- 左侧：当前组件属性配置。
- 右侧：数据集字段面板。

如果宽度不足，字段面板可以折叠。

当前组件配置分为三个 tab：

- **数据**：图表类型、维度槽、指标槽、过滤器、JS 转换入口。
- **样式**：标题、颜色、图例、标签、边距、表格样式、文本样式。
- **高级**：ECharts JSON、自定义 JS、导出相关配置。

字段面板只展示当前仪表盘数据集字段：

- 搜索字段。
- 维度字段。
- 指标字段。
- 数组对象数据集。
- 刷新/更新数据集入口。

字段面板不直接展示完整 JSON。完整 JSON、全量编辑、接口探针和 JS 清洗放入独立弹窗或抽屉。

## 6. 数据集交互需求

当前技术字段仍然使用 `schema.globalData`，本轮不改后端存储。

产品语义调整为：

- 对用户展示“当前数据集”。
- 右侧字段面板展示字段，而不是 JSON。
- 数据集入口负责更新数据、全量编辑、JS 清洗。

数据绑定方式：

- 柱状图/折线图/散点图：维度 + 指标。
- 饼图/漏斗图：名称 + 数值。
- 仪表盘：数值。
- 雷达图：v1 继续使用 JS 转换。
- 表格：选择数组对象数据集，自动识别列。
- 文本：不强依赖数据集。

## 7. 范围边界

本轮重构要做：

- 编辑器布局瘦身。
- 顶部组件栏。
- 右侧配置分层。
- 字段面板常驻化。
- 数据集 JSON/探针入口收纳。
- 去掉新增组件初始化弹窗。

本轮暂不做：

- 后端 API 重写。
- 独立数据源表/数据集表。
- 完整 DataEase 数据集模型。
- 权限、发布流、协作。
- 继续扩展更多 ECharts 类型。
- 大规模样式主题系统。

## 8. 验收标准

- 打开编辑器后，第一视觉重点是画布，而不是左侧配置面板。
- 可以从顶部工具栏直接添加文本、表格和图表。
- 添加组件后无需弹初始化弹窗，右侧自动切到对应配置。
- 右侧能看到组件配置和当前数据集字段。
- JSON 数据预览不再常驻占据编辑器空间。
- 已有任务能正常加载，旧图表、文本、表格不丢失。
- 保存、刷新恢复、预览、导出 Vue 仍然可用。
- 前端构建和后端 typecheck 通过。

## 9. 推荐实施顺序

1. 重构 `EditorView` 布局，移除左侧常驻面板。
2. 把添加组件入口迁移到顶部工具栏。
3. 去掉新增图表初始化弹窗，改为直接上屏。
4. 把右侧配置区改成“数据 / 样式 / 高级”tabs。
5. 新增右侧字段面板，展示当前数据集字段。
6. 将探针、全量编辑 JSON、JS 清洗收进数据集弹窗/抽屉。
7. 回归保存、刷新恢复、预览、导出。
