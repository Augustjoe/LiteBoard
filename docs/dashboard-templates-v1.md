# LiteBoard 模板系统 v1

更新日期：2026-06-25

## 目标

模板系统 v1 先解决“从空白创建太冷启动”的问题：用户可以在任务大厅的新建弹窗里选择内置模板，创建后直接进入编辑器，并继续使用现有保存、预览、导出链路。

## 当前实现

- 模板是前端本地内置数据，不新增后端模板 API。
- 模板创建流程复用现有任务接口：
  - `POST /api/tasks` 创建任务。
  - `PUT /api/tasks/:id` 写入模板生成的 `DashboardSchema`。
- 模板 schema 复用当前仪表盘 schema：
  - `canvas`
  - `components`
  - `globalData`
  - `createdAt / updatedAt`
- 模板只使用当前运行时和导出已支持的组件：
  - 文本
  - 指标卡
  - 普通表格
  - ECharts 图表

## 内置模板

| 模板 | 适用场景 | 组件 |
| --- | --- | --- |
| 销售经营 | 销售额、利润、目标完成率、渠道收入 | 文本、指标卡、柱状图、折线图、饼图、仪表盘、表格 |
| 运营监控 | 访问趋势、转化漏斗、接口延迟、运营明细 | 文本、指标卡、折线图、漏斗图、柱状图、表格 |
| 财务概览 | 收入、现金流、毛利率、成本结构 | 文本、指标卡、折线图、柱状图、饼图、表格 |

## v1 不做的事

- 不做模板上传。
- 不做模板市场。
- 不做远程模板库。
- 不做模板权限、版本、收藏。
- 不新增后端数据表。

## 后续方向

1. 把模板从前端本地数据迁移到后端模板列表。
2. 支持用户把当前仪表盘另存为模板。
3. 给模板增加缩略图和分类筛选。
4. 支持模板示例数据一键替换为用户自己的当前数据集。
