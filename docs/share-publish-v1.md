# LiteBoard 发布 / 分享 v1

更新日期：2026-06-25

## 目标

发布 / 分享 v1 补齐 LiteBoard 的最小交付出口：用户在编辑器保存仪表盘后，可以发布当前任务并获得一个只读分享链接。

本轮只做最小闭环：

`保存 -> 发布 -> 分享链接 -> 只读访问 -> 取消发布`

## 已实现能力

- 后端任务元信息增加 `published` 与 `publishedAt`。
- 新建和复制任务默认未发布，避免意外公开。
- 新增 `POST /api/tasks/:id/publish` 和 `POST /api/tasks/:id/unpublish`。
- 新增 `GET /api/share/:id`，只允许读取已发布任务。
- 前端新增 `/share/:taskId` 只读分享页，复用现有组件渲染能力。
- 编辑器顶栏新增发布 / 分享按钮。
- 发布前如果存在未保存改动，会先保存当前 schema，再发布。
- 发布弹窗支持复制分享链接、打开分享页、取消发布。
- 任务大厅卡片展示“已发布”标签。

## 边界

- 发布状态属于任务元信息，不写入 `DashboardSchema`。
- 分享页使用当前已保存 schema，不重新请求外部接口，不重新编辑数据集。
- v1 不做账号、访问密码、权限控制、水印、发布版本快照、发布历史。
- 取消发布会让 `/share/:taskId` 立即不可访问。
- 当前分享链接面向本地开发环境，格式为 `http://localhost:5173/share/:taskId`。

## 后续建议

- 如果进入多人使用阶段，需要给发布增加权限模型。
- 如果用户需要稳定线上交付，需要增加发布版本快照，避免编辑中的改动影响已发布页面。
- 如果要做公开分享管理中心，可以在任务大厅增加发布状态筛选、批量取消发布和访问统计。
