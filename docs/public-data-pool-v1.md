# 公共数据池 v1 实现说明

更新日期：2026-06-05

## 目标

当前版本先实现“一个仪表盘一个当前数据集”。每个仪表盘只维护一个 `globalData`，所有 ECharts 组件都从这个对象中读取数据并渲染。技术字段仍叫 `globalData`，产品语义上称为“当前数据集”。

v1 支持两种顶层数据形态。

字段数组形态，适合直接用字段下拉绑定：

```json
{
  "month": ["1月", "2月"],
  "sales": [150, 230],
  "profit": [80, 120]
}
```

数组对象形态，适合用图表级 JS 转换：

```json
{
  "data": [
    { "month": "1月", "sales": 150, "target": 200 },
    { "month": "2月", "sales": 230, "target": 200 }
  ]
}
```

## 已实现

- 后端新建任务默认 schema 使用 `globalData: null`。
- 前端加载旧任务时会兼容缺失 `globalData` 的 schema。
- 探针支持多次导入数据源，不再只作为首次初始化入口。
- 探针默认 JS 只保留极简示例，由用户按接口返回结构自行编写筛选逻辑。
- JS 过滤结果必须是普通对象，且每个字段值必须是数组。
- 导入前会检查同名字段；如果会覆盖已有字段，先在预览中提示，再在真正导入前二次确认。
- 字段数组长度不一致时给出警告，但不阻止写入。
- `mergeGlobalData` 采用字段级合并：新字段追加，同名字段整列替换。
- 图表字段下拉只读取 `globalData` 顶层数组字段。
- 柱状图和折线图默认优先绑定一个维度字段和一个数值字段。
- 图表运行时和导出代码都支持字段数组绑定，也支持图表级 JS 转换。
- 图表级 `customDataCode` 已作为 v1 正式能力，用于消费 `data: [{...}]` 这类数组对象数据集。
- 导出 Vue 代码会保留并执行图表级 `customDataCode`，导出不重新请求接口。
- 全量编辑全局数据弹窗已放大、可拖动、可调整大小，并支持 JS 筛选模式。

## 探针导入流程

1. 打开“导入数据源”。
2. 通过远程接口或手动 JSON 准备原始数据。
3. 在 JS 过滤器中编写转换逻辑。
4. 点击“预览结果”，查看最终字段数组对象。
5. 如果字段格式不正确，阻止导入并显示错误。
6. 如果有同名字段，提示将覆盖哪些字段。
7. 点击“导入到当前数据集”，确认覆盖后写入 `globalData`。

默认 JS：

```js
// res 是接口返回的原始数据。
// 请返回当前数据集对象：{ 字段名或数据集名: [...] }。
return res;
```

数组对象接口的常见转换示例：

```js
const fields = ['month', 'sales', 'profit', 'target'];

return Object.fromEntries(
  fields.map((field) => [
    field,
    res.map((row) => row[field]),
  ])
);
```

## 全量编辑流程

“全量编辑当前数据集”用于直接处理当前仪表盘已有的 `globalData`。

- JSON 模式：直接编辑字段数组对象。
- JS 筛选模式：变量 `data` 表示当前 JSON 草稿，JS 必须返回新的字段数组对象。
- 点击“预览 JS 结果”后，会把返回值写回 JSON 草稿。
- 点击“保存并全量替换”时，才真正替换 store 中的 `globalData`。
- 取消弹窗不会修改当前全局数据。

## 当前边界

- v1 不支持跨大屏共享数据源。
- v1 不保存多个数据源的来源记录，只保存最终合并后的 `globalData`。
- v1 不重新执行历史 JS；保存、恢复、导出都只使用已经写入 `globalData` 的结果。
- 普通表格组件和模板系统后置。
- 探针 JS 是用户代码执行能力，后续生产化必须增加安全限制。
- v1 不做独立数据源表、数据集表或数据库迁移。
