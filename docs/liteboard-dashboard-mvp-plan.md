# LiteBoard 仪表盘 MVP 产品化计划

更新日期：2026-06-25

## 定位

LiteBoard v1 收敛为轻量仪表盘设计器，参考 DataEase 的仪表盘体验，但不实现完整 BI 平台。

当前阶段的核心路径：

```text
接口取数 -> JS 清洗 -> 当前仪表盘数据集(globalData) -> 图表绑定/JS 转换 -> 拖拽布局 -> 保存恢复 -> 导出 Vue
```

## v1 决策

- 不新增后端 API。
- 不拆独立数据源表、数据集表或仪表盘表。
- 不做跨仪表盘共享数据源。
- `schema.globalData` 继续作为当前仪表盘唯一数据承载层。
- UI 文案上将 `globalData` 包装为“当前数据集”。
- 图表级 `customDataCode` 是正式能力，运行时与导出都必须支持。

## 当前数据集形态

字段数组形态适合普通字段下拉：

```json
{
  "month": ["1月", "2月"],
  "sales": [150, 230]
}
```

数组对象形态适合图表级 JS 转换：

```json
{
  "data": [
    { "month": "1月", "sales": 150 },
    { "month": "2月", "sales": 230 }
  ]
}
```

数组对象示例转换：

```js
const data = res.data;

return {
  xAxis: data.map((row) => row.month),
  yAxis: data.map((row) => row.sales),
};
```

## 已产品化的能力

- 顶部保存按钮显示保存状态：未保存、保存中、已保存、保存失败。
- 组件点选不再自动改变层级；置顶/置底改为显式操作。
- 右侧配置面板提供复制、置顶、置底、删除。
- 数据集面板展示顶层条目的类型：字段数组、数组对象、混合数组、空数组。
- 导出 Vue 代码支持图表级 `customDataCode`。
- 已支持文本、普通表格、指标卡和第一层核心 ECharts 图表。
- 预览模式已隐藏编辑器工具栏和多余配置面板。
- `npm run verify:mvp` 已覆盖数据导入、JS 清洗、组件添加、保存恢复、预览和导出 Vue SFC 编译检查。
- 任务大厅已收敛未实装入口，只保留当前真实可用操作。
- 新建弹窗已支持从内置模板创建仪表盘，模板复用现有 `DashboardSchema` 和任务 API。

## 后续优先级

1. 发布 / 分享：提供只读预览链接或发布态预览页。
2. 收藏 / 回收站：补真实任务字段和后端接口，不做前端假状态。
3. 数据源历史与字段元数据：记录导入来源、清洗脚本、字段说明和更新时间。
4. 模板系统增强：支持模板上传、另存为模板和模板库。
5. 多人使用与生产化：账号、权限、通知、协作、数据库存储和 Schema 迁移。
