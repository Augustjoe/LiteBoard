# LiteBoard 仪表盘 MVP 产品化计划

更新日期：2026-06-08

## 定位

LiteBoard v1 收敛为轻量仪表盘设计器，参考 DataEase 的仪表盘体验，但不实现完整 BI 平台。

当前阶段的核心路径：

```text
接口取数 -> JS 清洗 -> 当前仪表盘数据集(globalData) -> 图表绑定/JS 转换 -> 拖拽布局 -> 保存恢复 -> 导出 Vue
```

## v1 决策

- 不新增后端 API。
- 不拆独立数据源表、数据集表或仪表盘表。
- 不做跨仪表盘共享数据源。
- `schema.globalData` 继续作为当前仪表盘唯一数据承载层。
- UI 文案上将 `globalData` 包装为“当前数据集”。
- 图表级 `customDataCode` 是正式能力，运行时与导出都必须支持。

## 当前数据集形态

字段数组形态适合普通字段下拉：

```json
{
  "month": ["1月", "2月"],
  "sales": [150, 230]
}
```

数组对象形态适合图表级 JS 转换：

```json
{
  "data": [
    { "month": "1月", "sales": 150 },
    { "month": "2月", "sales": 230 }
  ]
}
```

数组对象示例转换：

```js
const data = res.data;

return {
  xAxis: data.map((row) => row.month),
  yAxis: data.map((row) => row.sales),
};
```

## 已产品化的能力

- 顶部保存按钮显示保存状态：未保存、保存中、已保存、保存失败。
- 组件点选不再自动改变层级；置顶/置底改为显式操作。
- 右侧配置面板提供复制、置顶、置底、删除。
- 数据集面板展示顶层条目的类型：字段数组、数组对象、混合数组、空数组。
- 导出 Vue 代码支持图表级 `customDataCode`。

## 后续优先级

1. 增加指标卡、文本、普通表格等 MVP 组件。
2. 优化真正预览模式，隐藏编辑器工具栏和多余滚动。
3. 为导出代码和数据集转换补自动化测试。
4. 后续再设计数据源历史、字段元数据和多数据集管理模块。
