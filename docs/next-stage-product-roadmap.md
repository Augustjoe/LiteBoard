# LiteBoard 下一阶段产品路线

更新日期：2026-06-25

## 当前判断

LiteBoard 当前已经具备轻量仪表盘设计器 MVP：用户可以导入数据、用 JS 清洗为当前数据集、添加图表/文本/表格/指标卡、拖拽排版、保存恢复、预览并导出 Vue。

下一阶段不要继续堆未实装入口，应该围绕“真实可交付产品”补齐能力。

## 推荐优先级

1. **模板系统 v1（已接入）**
   - 已内置销售经营、运营监控、财务概览 3 个前端本地模板。
   - 已支持从新建弹窗选择模板创建仪表盘。
   - 模板进入编辑器后仍按现有保存恢复和导出链路工作。

2. **发布 / 分享**
   - 先做只读预览链接或发布态预览页。
   - 明确发布使用已保存 schema，不在发布页重新编辑数据。
   - 后续再考虑访问权限、版本和撤回。

3. **收藏 / 回收站**
   - 收藏用于首页快速筛选。
   - 回收站需要先把删除从硬删除改为软删除。
   - 两者都需要真实任务字段和后端接口，不做前端假状态。

4. **数据源历史与字段元数据**
   - 保持 `globalData` 作为当前仪表盘数据承载层。
   - 增加数据导入来源、清洗脚本、字段说明和更新时间记录。
   - 不急于抽成跨仪表盘共享的数据源/数据集数据库。

5. **多人使用与生产化**
   - 引入账号、权限、通知、协作和审计日志。
   - 后端存储从本地 JSON 迁移到数据库。
   - 补 Schema 迁移、API 校验、安全限制和更完整的测试体系。

## 下一轮建议

模板 v1 完成后，下一轮建议优先做发布 / 分享最小闭环：基于已保存 schema 生成只读访问入口，让仪表盘具备真正交付出口。

模板 v1 细节见：`docs/dashboard-templates-v1.md`。
