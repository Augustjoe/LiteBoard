# 任务大厅未实装功能清单

更新日期：2026-06-25

## 背景

任务大厅已经完成“可信产品入口”收敛：首页只展示当前真实可用的操作，避免把模板、全局数据源、回收站、收藏、通知、帮助等未来能力提前暴露成空入口。

当前保留的真实入口：

- 新建仪表盘 / 从空白创建
- 编辑、预览、复制、删除
- 搜索仪表盘
- 更新时间筛选
- 最近更新
- 已发布状态展示

删除仍沿用当前硬删除 API，并保留二次确认。回收站能力后置，不做假入口。

## 已隐藏并后置的能力

| 功能 | 当前处理 | 后续真正实装需要补齐 |
| --- | --- | --- |
| 模板导入 | 首页独立入口隐藏；已在新建弹窗中接入内置模板创建。 | 后续如果恢复独立入口，需要补模板上传、远程模板库或模板市场。 |
| 管理数据源 | 首页入口隐藏。 | 当前仍采用“一个仪表盘一个当前数据集”。如要扩展，应先设计数据源历史、字段元数据和数据集更新记录。 |
| 回收站 | 首页入口隐藏。 | 删除改为软删除字段，新增恢复、永久删除和回收站列表。 |
| 收藏体系 | 左侧“我的收藏”和卡片星标隐藏。 | 任务收藏字段、收藏/取消收藏接口、收藏筛选和已收藏样式。 |
| 项目分组 | 前端关键字推断分组隐藏。 | 真实 `groupId` 字段、分组枚举或分组 CRUD、新建/编辑时选择分组。 |
| 项目状态 | “未保存”“协作中”等无真实状态的筛选隐藏。 | 任务状态字段、状态变更规则、多人协作或草稿来源。 |
| 视图切换 | 顶部网格/列表切换隐藏。 | 列表视图、本地或服务端偏好保存。 |
| 通知、帮助、用户菜单 | 顶部无行为按钮隐藏。 | 账号体系、通知来源、帮助文档或用户菜单。 |

## 仍可优化但已可用的能力

| 功能 | 当前表现 | 后续可改进点 |
| --- | --- | --- |
| 搜索 | 按名称和描述前端过滤。 | 任务量变大后再做服务端搜索、命中高亮和筛选持久化。 |
| 更新时间筛选 | 支持全部、今天、近 7 天、近 30 天。 | 可增加自定义日期范围。 |
| 新建仪表盘 | 弹窗创建空白仪表盘。 | 模板系统落地后可在新建流程里增加模板选择。 |
| 复制 | 调用现有复制接口。 | 复制成功后可高亮新仪表盘或自动定位。 |
| 删除 | 调用现有删除接口，删除前确认。 | 回收站落地时改为软删除。 |
| 预览 | 打开编辑器预览地址。 | 后续可继续优化独立预览页和加载失败提示。 |
| 发布状态展示 | 卡片可显示“已发布”，发布和取消发布在编辑器内完成。 | 后续可补发布筛选、分享管理和访问统计。 |

## 推荐实装顺序

1. **收藏 / 回收站**：增加真实任务字段和接口，改善任务管理体验。
2. **数据源历史与字段元数据**：在现有 `globalData` 方案稳定后，记录数据来源、清洗脚本和字段说明。
3. **模板系统增强**：从内置模板升级到模板上传、模板库和另存为模板。
4. **发布分享增强**：增加发布版本快照、访问权限和访问统计。
5. **账号、通知、协作**：进入多人使用路线后再引入，避免 MVP 阶段过早复杂化。

## 当前应避免的做法

- 不要把隐藏入口改成空弹窗或说明页来“假装实现”。
- 不要在没有真实字段和接口前恢复收藏、分组、状态、回收站入口。
- 不要在任务大厅先做独立数据源管理；当前数据集仍属于单个仪表盘内部能力。
- 不要提交本地验证产生的 `schemav-server/data/tasks.json` 改动，除非明确要把这些数据作为示例数据保留。
